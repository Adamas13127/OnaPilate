# Installation de Codex pour OnaPilates

## Installation Globale

Pour installer Codex globalement sur votre système :

```bash
npm i -g @openai/codex@latest
```

## Utilisation

Une fois installé, Codex peut être utilisé pour améliorer le développement du thème Shopify OnaPilates.

## Configuration

Le fichier `.cursorrules` est déjà configuré pour ce projet et sera automatiquement utilisé par Cursor/Codex.
